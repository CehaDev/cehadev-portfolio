# Daftar Ide Artikel (sumber untuk bot otomatis)

Bot membaca berkas ini untuk membuat artikel secara otomatis. Bot hanya memakai
ide yang berstatus `- [ ] `. Setelah dibuat (sebagai draft), ide ditandai `- [x] `.

Tambahkan ide lewat Telegram dengan perintah `/tambah-ide <topik>`.

Aturan untuk tiap baris:
- Mulai dengan `- [ ] ` lalu tulis satu topik/ide (satu ide per baris).
- Jangan menaruh data rahasia di sini.
